# vfl

The vfl language server for VHDL, Verilog and SystemVerilog: diagnostics, quick fixes,
formatting, hover, completion, go to definition, references, rename and semantic
highlighting.

It runs `vfl lsp`, so `vfl` must be on the `PATH` (or edit the command to its full path).
See [docs/editors.md](https://github.com/thewenneur/vhdl-fmt-lint/blob/main/docs/editors.md).
